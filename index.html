// benchmark

Making capable AI models run fast on real hardware.

I build lean C/C++ inference engines that bring VLMs, VLAs, and LLMs to CPUs, accelerators, and robots. Inspired by llama.cpp: a few lines of simple code, big results on your own hardware. The two projects I'm proudest of are vla.cpp and vla.simd - compare their measured latency across devices in the explorer. Three companion pages go deeper: VLA Hub benchmarks every model they serve on every device, VLA Arch illustrates each model's architecture as block diagrams, and XPU Arch diagrams the CPUs, GPUs, NPUs and systems on chip behind VLA Hub.

    vla.simd

    Efficient CPU inference for language-conditioned manipulation - shared SIMD micro-kernels (AVX2 / NEON) plus IMPACT, a language-conditioned policy that supplies 30+ actions per second on a Raspberry Pi 5.

    C++SIMDCPU inferenceVLA

    K.D. Nguyen, H.M. Truong, A.T. Le

    FoldQuantVLA

    Native low-bit quantization of VLA models - W8A8 and W4A4 projections run on the INT8 / INT4 tensor cores through custom TensorRT plugins, 1.20-1.33× faster than float TensorRT on Jetson AGX Orin across GR00T and π0.5.

    QuantizationTensorRTINT4VLA

    H.T. Ho, K.D. Nguyen, Q.D. Nguyen, T.Q. Duong, N. Le, M. Guo, V.A. Ngo, A.T. Le

    View on GitHub ↗

    ggml-compiler

    Compiles PyTorch and ONNX models into ggml programs that run on CPU and CUDA without Python - LLMs, VLMs and the robot policies built on them, each checked against llama.cpp and vla.cpp.
